# DNSentinel

An ESP32-based DNS sinkhole designed to block unwanted domains at the network level.

## Current Features
- DNS packet parsing
- Domain blocking
- DNS responses
- Upstream DNS forwarding
- Request statistics

## Hardware
- ESP32-S3-WROOM-1 N16R8

## Planned Features
- DNS caching
- Web dashboard
- Larger blocklists
- ESP32-P4 Ethernet version
